# Systems Specification

## Core Mechanics

*   **Resource Gathering:** Wood and Stone gathering systems.
*   **Modular Building:** Grid-based construction system.
*   **NPC Protection:** Defending NPCs from environmental and external threats.

## Android Testing

The game automatically builds an APK whenever changes are pushed to the `main` branch.
To download and test the game on an Android device:

1.  Navigate to the **Actions** tab on the GitHub repository.
2.  Click on the latest successful run of the **Godot 4 Android Build** workflow.
3.  Scroll down to the **Artifacts** section at the bottom of the page.
4.  Click on the `Android-APK` link to download the `.zip` file containing the game's APK.
5.  Extract the `.apk`, transfer it to your Android device, and install it.
